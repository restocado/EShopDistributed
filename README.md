# EShopDistributed

## Overview
This repository is part of my learning journey while following the Udemy course:  
**Develop AI-Powered Distributed Architecture w/ PostgreSQL, Redis, RabbitMQ, Keycloak, Ollama, VectorDB using .NET Aspire**

The goal is to build a distributed, cloud-native architecture powered by modern technologies and AI integration.  
It serves as a **learning project** — open for viewing, but **not open for contributions**.

## Tech Stack
- **.NET Aspire** – orchestration, observability, and service integration
- **ASP.NET Core Web API** – microservices (e.g., Catalog service)
- **PostgreSQL** – relational database with EF Core migrations
- **Redis** – caching and fast key-value storage
- **RabbitMQ** – message broker for event-driven communication
- **Keycloak** – identity and access management
- **Ollama** – local LLM runtime for AI-powered features
- **VectorDB** – embedding storage for semantic search and retrieval

## Features
- Catalog microservice with CRUD endpoints
- EF Core migrations and seeding
- Identity integration with Keycloak
- Event-driven messaging via RabbitMQ
- Redis caching for performance
- AI-powered search/recommendation with Ollama + VectorDB
- Orchestration and monitoring with .NET Aspire
